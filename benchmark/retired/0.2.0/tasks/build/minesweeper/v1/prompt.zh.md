# 构建任务：扫雷

实现一个完成度良好、可实际游玩的扫雷游戏。

## 必须实现

- 默认 10×10、10 个地雷。
- 左键翻开；右键切换旗帜并阻止浏览器右键菜单。
- 显示剩余雷数、时间和游戏状态。
- 数字统计周围八格。翻开 0 时递归展开相连安全区及其数字边界。
- 已插旗格不能翻开；踩雷后失败并显示全部地雷。
- 翻开全部安全格后胜利；结束后禁止继续操作。
- 重开清理棋盘、计时器、旗帜和终局状态。

## 公开自动化契约

桥接动作包括带 `{row,col}` 的 `reveal`、`toggle-flag` 及 `restart`。
Snapshot state 符合 `state.schema.json`。DOM 格子使用
`data-cell="row-col"`，用于验证真实指针输入。

Fixture：`corner-count` 仅在 `[1,1]` 有雷；`flood-region` 仅最后一列
有雷；`flag-cell` 在 `[1,1]` 有雷；`near-win` 只剩 `[0,0]` 一个安全格
未翻开。确定性 fixture 含 10 个雷，并将 `mineSignature` 报告为
`0,7;1,3;2,8;3,1;4,6;5,4;6,9;7,2;8,5;9,0`。

不得运行时读取测试或针对评测器写特殊分支；不得发起运行时网络请求。
