# 构建任务：2D 停车

实现俯视角驾驶停车游戏，玩家需要将车辆停入指定车位。本任务不是移车解谜。

## 必须实现

- 至少三个真正不同的关卡，包含边界、障碍、已停车辆、起始姿态和目标车位。
- W/上键加速，S/下键倒车，A/D 或左右键转向，空格刹车。车辆沿自身朝向
  运动，并具备加速度、阻力和速度限制。
- 倒车转向路径符合直觉；静止时不能快速原地旋转。
- 使用带朝向的车辆轮廓检测碰撞。碰撞增加计数、有可见反馈且不能穿墙。
- 只有整车进入车位、方向接近且速度接近 0 时通关。显示时间、碰撞、结果、
  重开和关卡选择。

## 公开自动化契约

桥接动作：`throttle`、`reverse`、`steer-left`、`steer-right`、`brake`、
`release-controls`、`pause`、`restart`，以及带 `{level}` 的
`select-level`。Snapshot 符合 `state.schema.json`。

Fixture：`motion` 从 `(400,400)`、角度 0 开始；`reverse-turn` 同位置；
`collision` 面向十像素外的墙；`parked` 已居中、对齐且速度为 0；
`level-2` 的签名为 `reverse-bay`。真实键盘必须与桥接动作共用控制状态。

不得发起运行时网络请求或编写评测器专用分支。
