# 构建任务：2048

实现一个完成度良好、可实际游玩的浏览器版 2048。

## 必须实现

- 4×4 棋盘，正常新局生成两个数字块。
- 方向键移动；相邻相同数字在一次移动中只能合并一次。
- `[2,2,2,0] → [4,2,0,0]`，`[2,2,2,2] → [4,4,0,0]`。
- 仅在有效移动后生成一个 2 或 4，且 2 的概率更高。
- 显示分数、重新开始、2048 胜利状态及无合法移动时的失败状态。
- 快速输入和重开不得破坏游戏状态。

## 公开自动化契约

桥接动作包括 `start`、带 `{direction:"left|right|up|down"}` 的 `move`
以及 `restart`。Snapshot 的 state 必须符合 `state.schema.json`。

测试场景是公开 fixture：`merge-2220` 第一行为 `[2,2,2,0]`；
`no-op-left` 是已经向左压紧且 `spawnCount=0` 的棋盘；`near-win`
包含两个相邻的 1024；`deterministic` 在种子 `104729` 下将两个 2
放在 `[0,0]` 和 `[1,1]`。Fixture 初始数字不计入 spawnCount。
真实方向键必须与桥接动作共用同一套移动逻辑。

不得在运行时读取测试文件或针对评测器写特殊分支；不得发起运行时网络请求。
