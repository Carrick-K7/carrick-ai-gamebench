# 2048（游玩模式）

你在操作一个 4x4 的 2048 棋盘，使用方向键控制。

## 规则

- 棋盘为 4x4 网格，开局时已有两个方块。
- 每次移动让所有方块朝一个方向（上 / 下 / 左 / 右）滑到不能再滑为止，
  直到被方块或边框挡住。
- 当两个数值相同的方块碰撞时，会合并成一个数值翻倍的方块；每个方块每次
  移动最多合并一次。
- 合并会把你合并出的方块数值计入得分。整局得分为所有合并方块数值之和。
- 任何真正改变棋盘的移动之后，会在一个随机空位产生一个新方块：多数情况是
  2（90%），少数情况是 4（10%）。
- 没有改变棋盘的移动不会产生任何效果，也不会新增方块。

## 目标与结束

- 在最多 200 次决策内尽可能提高原生合并得分。这是限步得分任务，不以合成出
  2048 方块作为完成条件。
- 当无法做出任何改变棋盘的移动（棋盘已满且没有相邻的同数值方块）时游戏结束，
  此时已获得的分数即为你的成绩。
- 你的决策次数有限，每次决策都会消耗一次，无论该移动是否改变了棋盘。
- 每次决策只能移动一次，没有撤销，也不能重新开始。
- 每次回答限时 60 秒。无效回答也消耗一次决策；连续三次无效回答会结束本局。
  达到次数、回答限时或无效回答上限时，保留已经获得的合并得分。

## 操作

- ArrowUp 让所有方块向上移动。
- ArrowDown 让所有方块向下移动。
- ArrowLeft 让所有方块向左移动。
- ArrowRight 让所有方块向右移动。

你只能看到当前截图、这些规则、剩余的决策预算、你最近的行动以及你自己的简短
备忘。请根据截图中的棋盘决定下一次按键的方向。
