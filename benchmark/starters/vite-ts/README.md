# CAGB Vite + TypeScript starter

Submissions may replace the rendering framework and project layout, but must:

- keep `pnpm build` and `pnpm preview --host <host> --port <port>` working;
- commit an exact `pnpm-lock.yaml`;
- make no runtime network requests;
- implement `window.__CARRICK_GAMEBENCH__` version 1;
- render and accept real mouse/keyboard input in addition to bridge actions.
