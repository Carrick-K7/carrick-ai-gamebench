# 复刻任务：OhSteem

根据提供的 OhSteem 参考包复刻其玩法、交互手感和视觉特征。本任务基于
`THIRD_PARTY.yml` 中固定提交的 MIT 项目，但运行过程中不得搜索或复制源码。

## 要求范围

- 包含首页/尺寸选择，以及可游玩的 4×4、6×6 二元逻辑棋盘。
- 可编辑格依次循环：空白 → 橙色 → 蓝色 → 空白。
- 完整行列中橙色和蓝色数量相等。
- 行列内不得出现连续三个同色。
- 任意两条完整行不能相同，列也同样如此。
- 提示格具有明确固定样式且不可编辑。
- 非法状态提供即时、可见反馈，但不要直接销毁玩家落子。
- 正确检测完成状态，提供胜利反馈和干净的新局。
- 复刻参考图中的字体、暖橙、深蓝、间距、格子动效和紧凑移动端构图。

参考材料位于 `$CAGB_REFERENCE_DIR/reference/index.html`。首页和游戏区分别
使用 `#game-menu`（950×569）及 `#game-board`（788×652）作为视觉检查点。
可编辑格使用 `data-cell="row-col"`。

桥接动作：带 `{row,col}` 的 `cell`、带 `{size}` 的 `select-size` 及
`new-game`。Snapshot 符合 `state.schema.json`。Fixture 行为已在公开测试
中完整声明。不得发起运行时网络请求。
